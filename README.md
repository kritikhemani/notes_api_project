# Notes API (FastAPI)

A secure and scalable REST API for managing personal notes, built with **FastAPI**.


## 🚀 Features

- 🔐 JWT-based Authentication (Login/Register)
- 🧾 CRUD operations for Notes
- 👤 User-specific data access (Authorization)
- ⚡ FastAPI with async support
- 🐘 PostgreSQL database
- 🐳 Docker support
- 🚀 Deployment-ready (Render/Railway/Fly.io)
- 🛡️ Security hardening (OWASP API Top-10)

---


## 🏗️ Tech Stack

- **Backend:** FastAPI
- **Database:** PostgreSQL
- **ORM:** SQLAlchemy
- **Authentication:** JWT (OAuth2)
- **Containerization:** Docker
- **Deployment:** Render / Railway / Fly.io
- **CI/CD:** GitHub Actions
